# 🚀 Lean Automate 365 | Consultoría Industrial Low-Cost

¡Bienvenido al repositorio oficial de la web de **Lean Automate 365**! Este proyecto nace con un objetivo claro: ayudar a las plantas de fabricación y entornos industriales a digitalizar sus operaciones sin incurrir en los desorbitados costes de licencias de software tradicionales.

Transformamos procesos manuales, registros en papel y hojas de Excel caóticas en aplicaciones móviles ágiles y paneles dinámicos, exprimiendo al máximo el entorno **Microsoft 365** que las empresas ya pagan en su día a día.

---

## 🛠️ Nuestras Soluciones Básicas

*   **GMAO Low-Cost:** Gestión de mantenimiento correctivo/preventivo y control de stock de repuestos desde movilidad utilizando **PowerApps** y **SharePoint**.
*   **Digitalización de Formularios:** Auditorías de seguridad, listas de control de calidad o auditorías 5S con flujos de aprobación automáticos vía **Power Automate**.
*   **Paneles de Control OEE & KPIs:** Extracción, limpieza y visualización de pérdidas o paradas de línea en tiempo real con **Power BI**.

---

## 💻 Sobre esta Página Web

Este repositorio contiene el código fuente de nuestra *landing page* principal. Ha sido diseñada buscando la máxima ligereza, velocidad de carga y un diseño limpio y profesional adaptado a la identidad corporativa de Microsoft del entorno industrial.

### Tecnologías utilizadas:
*   **HTML5:** Estructuración semántica del contenido de la web.
*   **CSS3:** Estilos personalizados, diseño responsive adaptado a móviles y ordenadores, y uso de variables globales (`:root`) para una fácil edición de colores.
*   **JavaScript:** Interactividad básica y lógica para la simulación del formulario de contacto técnico.
